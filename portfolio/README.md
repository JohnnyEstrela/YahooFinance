# Portefólio & Watchlist

1. Edita `portfolio.json`: adiciona empresas em `holdings` (portefólio) ou `watchlist` (a seguir). Limites de P/E e PEG também estão aqui.
2. `pip install yfinance && python3 portfolio/update.py` → gera `data.json` e `index.html` (abrir no browser; tema, filtros, ordenação e vistas Cartões/Tabela/Notícias guardam-se no browser).

Classificação: P/E (12m e próx. 12m) Barato <15 · Justo <30 (ref. 20) · Caro <50 (ref. 40) · Muito caro ≥50. PEG Desconto <1 · Justo 1–2 · Prémio >2.
